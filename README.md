# Megamania Remake

Um remake fiel ao clássico "Megamania" do Atari, desenvolvido com JavaScript moderno e HTML5 Canvas.

## 🚀 Tecnologias

- **Vite**: Ferramenta de build extremamente rápida.
- **JavaScript (ES6+)**: Lógica do jogo.
- **HTML5 Canvas**: Renderização de alta performance.
- **CSS3**: Estilização e layout.
- **Web Audio API**: Geração de áudio procedural (sem arquivos externos).

## 🎮 Como Jogar

1. **Instale as dependências**:
   ```bash
   npm install
   ```
2. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```
3. **Controles**:
   - `N`: Iniciar novo jogo / Reiniciar após Game Over.
   - `Setas (Esquerda/Direita)`: Movimentar a nave.
   - `Espaço`: Atirar.

## ⚙️ Funcionalidades

- **Mecânica de Combustível**: Sua energia diminui constantemente. Destrua ondas completas para recarregar.
- **Ondas Variadas**: Inimigos mudam a cada nível (Hambúrgueres, Biscoitos, Ferros de Passar, Gravatas e Diamantes).
- **Dificuldade Progressiva**: A velocidade dos inimigos aumenta a cada nível.
- **Áudio Retrô**: Sons de laser e explosões gerados via código.
